# Lightair Effect Stack data

Copied unchanged from the desktop's Lightair Effect Stack module (`../lightair/modules/lightair-effect-stack`,
commit `5fda5cd`), for the phone engine's looks (`src/looks/`). Edit them there, then copy them here
again, so both apps look the same.

| File here | Source in the desktop module | Used by |
|---|---|---|
| `lights.json` | `data/lights.json` | `looks::render` (Relight presets) |
| `filters.json` | `data/filters.json` | `looks::grade` (Colour grade presets → 25³ LUT) |
| `makeup/presets.json` | `data/makeup/presets.json` | `looks::render` (makeup looks) |
| `makeup/face-paint.png` | `data/makeup/face-paint.png` | `looks::mesh` (contour, highlight, brow, drawn through the face mesh) |
| `makeup/face-liner.png` | `data/makeup/face-liner.png` | `looks::mesh` (the eyeliner styles) |
| `makeup/face-normal.png` | `data/makeup/face-normal.png` | `looks::mesh` (the face's surface directions, for the light) |

The three PNGs and `src/looks/mesh.rs`'s mesh tables are generated by the desktop module's
`tools/gen-face-paint.py` from Google MediaPipe's canonical face model (© Google LLC,
Apache-2.0; see the desktop module's `data/models/NOTICE.md`).
